# 校园网自动登录守护（CampusNet AutoLogin）

Windows 托盘常驻小工具：定时检测校园网是否断网，断网后自动用隐藏浏览器打开学校认证页、填入账号密码并点击登录，全程无需人工干预。带图形设置窗口、迷你看板、临时计时器、一键退出登录、新手引导、状态变色托盘图标与系统气泡通知。

## 工作原理

```
托盘常驻（校园网守护中...）
        │  每 check_interval 秒
        ▼
ping external_test_url（如 www.baidu.com）──通──► 休眠，等待下一轮
        │ 不通
        ▼
HTTP 兜底探测（禁止跟随重定向，识别门户劫持）──通──► ICMP 被拦但实际在线，休眠
        │ 不通
        ▼
连续 2 次 ping 确认 ──任一次通──► 判为偶发丢包，休眠
        │ 全不通
        ▼
ping internal_test_url（认证服务器）──不通──► 记日志（多半是网线/Wi-Fi 没连上）
        │ 通
        ▼
隐藏浏览器打开 login_url → 注入 JS 填账号密码、点击登录按钮
        │
        ▼
轮询"注销按钮"是否出现 → 出现即登录成功（气泡通知）
```

探测实现：Windows 上 ping 走系统 `IcmpSendEcho`（与 cmd 的 ping 同款 API，
不受 raw socket 防火墙策略影响——ping3 在部分机器上会被整条拦掉而 cmd ping
正常）；非 Windows 用 ping3。外网判定按「ping → HTTP → ping 确认」级联，
**任一通道判在线立即返回**：ping 失败后先做 HTTP 兜底（ICMP 被拦的环境
约 5 秒出结果），HTTP 也不通再做第 2、3 次 ping 确认（防偶发丢包），全部
失败才认为离线。

登录连续失败时按 `max_retries` / `retry_delay` 退避，避免频繁撞击认证服务器。

## 快速开始

```bash
pip install -r requirements.txt
python run.py
```

1. 首次运行会弹出**设置窗口**并自动进入**新手引导**（3 步图文：怎么找认证页地址、怎么用 F12 找元素 ID），照着填 4 个必填项即可：
   - 登录账号（一般是学号）
   - 登录密码
   - 认证页地址：断网时随便打开一个网页被跳转到的那个地址，如 `http://10.1.1.55/srun_portal_pc?ac_id=1`
   - 内网探测地址：一般是认证服务器的 IP，如 `10.1.1.55`
2. 点击「保存并应用」，窗口收起，守护自动开始；之后可随时从托盘菜单「打开设置」修改（保存即时生效），点窗口里的「帮助」可重看引导。
3. 也可以不用窗口，直接编辑程序目录下的 `config.ini`（字段说明见下表），改完重启程序生效。

## 界面说明

### 托盘菜单

| 菜单项 | 说明 |
|---|---|
| **打开看板** | 左键点击托盘图标即弹出/收起迷你看板（default 项） |
| 状态：××× | 实时状态（已连接 / 正在登录 / 正在退出登录 / 被门户拦截 / 网络离线 / 已暂停 / 等待配置） |
| 打开设置... | 设置窗口（状态、配置表单、新手引导；计时器在迷你看板中） |
| 立即检测登录 | 不等下个周期，立刻执行一轮检测，需要登录时马上尝试 |
| 暂停守护 / 恢复守护 | 临时停用/恢复自动登录 |
| 自动退出：剩余 ×× / 延长 30 分钟 / 取消计时 | 仅在计时器启动后出现 |
| 打开日志文件夹 | 打开 logs/ 目录查看运行日志 |
| 如何常显托盘图标 | 打开系统设置页并说明步骤（Windows 默认把新图标收进溢出区） |
| 退出守护程序 | 清理并退出 |

### 托盘图标颜色

| 颜色 | 含义 |
|---|---|
| 绿色 | 在校且网络正常 |
| 蓝色 | 已连接且计时器运行中 |
| 黄色 | 已联网但非校园网（内网 ping 不通） |
| 红色 | 网络异常（离线 / 门户拦截） |
| 灰色 | 等待配置 / 已暂停 |
| 呼吸脉动 | 正在登录或退出登录的过程中 |

### 迷你看板（托盘左键）

小窗包含：实时状态徽章与计数、临时计时器（大字倒计时）、快捷按钮（立即检测 / 暂停恢复 / 打开设置 / 关闭）以及红色「退出登录」按钮。

### 临时计时器

适合**学校/借用电脑临时用机**：到时程序自动退出，不写常驻进程；计时器只在本次运行内有效，不写入配置文件。

- 界面入口：看板或设置窗口的「临时计时器」卡片
  - 按时长：输入分钟数 → 开始
  - 按到点：选择具体时刻 → 到点退出（时刻已过则自动次日生效）
  - 延长：输入任意分钟数 → 延长（不再固定 30 分钟）
  - 到期前自适应提醒：长计时提前 5 分钟，短计时（如 1 分钟）在剩余约一半时提醒
- 命令行入口：

```bash
python run.py --timer 120      # 守护 120 分钟后自动退出（打包 exe 同样支持）
python run.py --until 22:30    # 运行到 22:30 自动退出（已过则次日生效）
python run.py --once           # 单次运行：登录成功（或本就在线）后自动退出
```

`--timer` 与 `--until` 只能二选一；`--once` 登录失败会按常规重试直到成功。

登录成功 / 登录失败 / 网络不可达 / 计时临近结束 / 退出登录等状态变化都会弹系统气泡通知（可在设置窗口「高级选项」中关闭）。

### 一键退出登录

迷你看板中的红色「退出登录」按钮：通过隐藏浏览器点击认证页的注销按钮，并自动处理门户的确认弹窗（SweetAlert/Layer 等常见样式）；确认后以**外网连通性变化**做最终判定（会话真被注销则外网必然断开）。**退出成功后守护会自动暂停**（防止 45 秒内被自动重新登录），恢复需从看板或托盘手动操作。

自动确认失败时按设置页「探测与高级 → 退出登录兜底方式」兜底：

- **browser（默认）**：用系统浏览器打开认证页，手动注销后从托盘「恢复守护」；
- **window**：弹出应用内认证页窗口，手动注销后**关闭窗口会自动 ping 外网播报退出结果**；
- **manual**：不尝试自动点击，直接弹出应用内认证页窗口人工操作——适合注销确认弹窗非标准、自动点击不兼容的门户（如 srun theme=pro）；
- **none**：仅报失败。

所有"外网已断开"的判定均要求**连续 3 次 ping 失败**（间隔 1.5 秒），避免单次丢包造成误报。

### 界面主题

设置窗口右上角可切换 **跟随系统 / 浅色 / 深色**，即时生效并持久化；迷你看板 1 秒内自动跟随，无需重启。跟随系统模式下随 Windows 的应用深浅色设置变化。手动退出登录窗口加载的是外部门户页面，不受此设置影响。

## config.ini 配置说明

| 段 | 键 | 默认值 | 说明 |
|---|---|---|---|
| Account | username | （空） | 必填，登录账号 |
| Account | password | （空） | 必填，登录密码 |
| Settings | login_url | （空） | 必填，认证页完整地址（http:// 或 https:// 开头） |
| Settings | internal_test_url | （空） | 必填，内网探测地址（通常为认证服务器 IP） |
| Settings | external_test_url | www.baidu.com | 外网连通性探测地址 |
| Settings | check_interval | 45 | 检测间隔（秒） |
| Settings | quick_retry_times | 2 | 每轮登录额外重试次数（实际尝试 = 该值 + 1） |
| Settings | max_retries | 3 | 连续失败多少轮后进入退避等待 |
| Settings | retry_delay | 180 | 退避等待时长（秒） |
| Settings | show_notifications | true | 状态变化时是否弹系统气泡通知 |
| Settings | logout_fallback | browser | 一键退出登录兜底：browser=系统浏览器 / window=应用内窗口 / manual=强制应用内窗口（跳过自动流程） / none=不兜底 |
| Settings | ui_theme | system | 界面主题：system=跟随系统 / light=浅色 / dark=深色 |
| Settings | username_input_id | username | 认证页账号输入框的元素 ID |
| Settings | password_input_id | password | 认证页密码输入框的元素 ID |
| Settings | login_btn_id | login-account | 认证页登录按钮的元素 ID |
| Settings | logout_btn_id | logout | 用于判断登录成功的"注销"按钮元素 ID |

> 换学校/换门户时：在认证页按 F12，用元素检查器找到账号框、密码框、登录按钮、注销按钮的 `id`，在设置窗口「高级选项」或 config.ini 中修改即可，无需改代码。
>
> 通过设置窗口保存的配置**立即生效**（无需重启）；手改 config.ini 则需重启程序。

```bat

```

## 环境隔离机制

`config.ini` 是一个极易与其它软件重名的文件名。启动时程序会检查运行目录：

- 已有的 `config.ini` 若不含本程序签名（`System.app_signature`），判定为别人的配置 → 触发隔离；
- 首次运行时若目录里杂项文件过多（超过 2 个无关文件），为避免弄脏目录 → 触发隔离。

触发隔离时，程序会把自身复制到 `CampusNet_Isolated_Env[_时间戳]/` 子文件夹并退出，请进入新文件夹重新运行。

## 日志与排障

日志同时输出到控制台与 `logs/campus_net.log`（单文件 1MB，最多保留 3 个历史），托盘菜单可一键打开日志文件夹。

常见问题：

- **状态一直是"网络离线"**：外部与内网探测地址都 ping 不通，多半是网线/Wi-Fi 未连接，或 `internal_test_url` 配错。
- **状态是"被门户拦截"但一直登录失败**：看日志是否提示"未找到账号/密码输入框"——门户页面元素 ID 与默认值不同，按 F12 方法修改（新手引导第 3 步有说明）。
- **实际能上网但程序反复登录**：v0.9.1 起外网判定改为「3 连 ping + HTTP 兜底」，若仍出现请把日志发来——现在每次探测失败都会记录是哪条通道（系统 ICMP / ping3 / HTTP）失败及原因。
- **托盘图标找不到**：多半被收进了任务栏溢出区（^），用托盘菜单「如何常显托盘图标」按指引设置。

## 后续可选改进

- **HTTP 直连登录**：`login-account` 按钮是 Dr.COM 类门户的典型特征，若确认学校门户接口，可改用 requests 直接 POST 登录，去掉 pywebview 依赖，登录从十几秒缩短到 1 秒内。
- **HTTP 204 探测替代 ping**：更贴近"能否上外网"的真实语义。
- **密码加密存储**：改用 Windows 凭据管理器（DPAPI）。
